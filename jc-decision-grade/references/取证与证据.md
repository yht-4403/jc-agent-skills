# 取证与证据

事实底稿的质量，取决于你查的是原始来源还是别人的转述。这一份解决三件事：去哪里找、怎么分级、什么不算证据。

## 一、先分清三类内容

| 类型 | 定义 | 写法 | 常见错误 |
|---|---|---|---|
| 已知事实 | 有外部来源，别人可以复核 | 事实 + 来源 + 日期 + 口径 | 把用户判断、行业常识写进来 |
| 推断 | 你基于事实做的解释 | 推断 + 依据 + 什么情况下不成立 | 写成陈述句，看不出是推断 |
| 未知 | 影响判断但目前没有数据 | 缺口 + 影响 + 获取成本 | 直接跳过，用假设填上 |

一条内容只能属于一类。既像事实又像推断的，拆成两条。

判断标准很简单：换一个人拿到同样的来源，会不会得出同样的话？会，是事实；不会，是推断。

## 二、来源分级

- **A 一手且可复核**：原始数据表、官方文件、监管备案、财报原文、你自己跑出来的实验结果、可访问的原始访谈记录。
- **B 一手但不可复核**：内部经营数据、未公开的访谈、客户口头反馈。标注样本量和采集方式。
- **C 二手转述**：媒体报道、报告摘要、他人总结、行业文章。只能做背景，不能单独支撑核心结论。
- **D 推测**：模型推断、行业常识、类比。必须显式标“推断”。

硬规则：

1. 核心结论至少一个 A，或两个互相独立的 B。
2. C 不能单独支撑任何一个关键数字。
3. D 不能出现在“事实”栏。
4. 同一个来源被多篇文章引用，仍然只算一个来源。
5. 当事人自述、单方报价、口头承诺、未签字的意向，在拿到文件或第三方证据前一律按 D 处理；核实后升到 B。不要因为“是本人说的”就放进事实栏。

## 三、去哪里找：按问题类型分

### 市场与竞争

- 行业协会的年度统计原始表，不看新闻稿里的摘录；
- 上市公司财报、招股书、投资者电话会记录；
- 监管部门的备案、许可、处罚公告；
- 政府采购和招投标公告（能看出真实预算和供应商）；
- 专利数据库（看技术投入方向，不看宣传）；
- 招聘岗位和 JD（在招什么人，说明真实业务重心）；
- 应用商店评论、社区帖子、客服工单（看真实抱怨，不看宣传语）；
- 电商平台的销量、评价、退货理由。

### 用户需求

- 访谈原始记录，不是访谈总结；
- 客服工单分类和频次；
- 搜索词和站内搜索无结果词；
- 试用转化、激活、留存、退款原因；
- 用户实际付费记录，不是“愿意付费”的表态。

意愿和付费是两件事。问卷里说“愿意买”的人，和真实掏钱的人，通常差一个数量级。有真实成交记录就用成交记录，没有就标“未验证”。

### 技术可行性

- 官方文档和 changelog，不看二手中文教程；
- 基准测试的原始数据、测试条件和版本号；
- 项目的 issue tracker（看真实故障和维护状态）；
- 自己跑一遍最小复现实验；
- 压测和成本实测（云账单比报价单可信）。

### 财务

- 单位经济：每个客户/每单的收入、直接成本、履约成本、获客成本；
- 现金流：什么时候花钱、什么时候收钱、中间差多少；
- 隐性成本清单：集成、数据迁移、培训、合规、运维、退款、坏账；
- 敏感性：哪个假设变动 20% 会让模型翻负。

### 法务与合规

- 监管原文和实施细则，不看解读文章；
- 相关判例和处罚案例；
- 牌照、资质、备案要求；
- 合同里的责任、违约、数据归属、退出条款。

涉及牌照、税务、合同责任的结论，标“需专业复核”，写清找哪类专业人士复核，不要让模型结论直接上线。

## 四、反例怎么找

每个核心判断，至少往四个方向各找一次：

1. **替代解释**：同样的现象，有没有另一种更简单的解释？
2. **反事实**：如果这个判断是错的，我们现在应该看到什么？现实中看到了吗？
3. **失败案例**：同类事情有没有人做过并且失败了？失败原因和我们像不像？
4. **利益相关者反对**：客户为什么不买、合作方为什么不签、监管为什么拦、对手会怎么反击？

找不到反例时，不要写“未发现反例”，写“查了哪几个方向、用了什么关键词、覆盖到什么时间范围”。搜不到和不存在是两件事。

## 五、看起来像证据，其实不是

- **单一成功案例**：尤其是创始人访谈和品牌故事，幸存者偏差最重。
- **自选样本**：只统计留下来的用户、只访谈满意的客户。
- **无日期数据**：市场数字每年在变，没有年份的规模数据不能用。
- **把相关当因果**：两个数一起涨，不代表一个导致另一个。
- **把 TAM 当可得市场**：行业总规模不等于你能触达、能服务、能收费的那部分。
- **把意愿当付费**：问卷、点赞、加购都不等于付款。
- **把媒体报道当原始数据**：媒体引用的数字经常二次加工，回到原始报告。
- **把模型输出当外部证据**：模型生成的案例、数据、引用，默认都是 D，除非能点开原始链接核对。

## 六、记录格式

每条关键证据记五个字段：

```text
结论/数字：
来源：（文件、链接、访谈编号）
日期与口径：（统计期、样本量、币种、是否含税）
等级：A / B / C / D
可核验性：（别人怎么复核；不能复核的原因）
```

证据多的时候单独建一份台账，主文档只放结论和引用编号。台账格式见 [交付骨架](交付骨架.md)。
