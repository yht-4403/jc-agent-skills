# 日常英语语义块记忆卡

把你开会、聊天、网页里碰到的话，做成墨墨记忆卡：正面一句英文，用来测能不能按块秒懂；背面才切开、讲 `for` / `into` 这种逻辑，并补上美国人更常说的说法。

和把单词丢进背单词词本不同。这里认的是整句和词块，不是考纲表。

适合：商务洽谈、企业面试里的自我介绍和过往经历、日常聊天，以及工作原话、App 英文。不适合：雅思词表、只想存进知识库、改简历。

丢材料就会拆并写入牌组「英语」。从知识库或过往文案抽句时，只做一个主题，按把这件事讲完需要的深度做成连贯开口链；你指定场景或说「再来一批」就按那个主题继续。什么都不贴、只调用本 Skill 时，会从今天的 Grok 对话用户原文里抽一个主题再写入。开放接口只负责写卡，新卡要在记忆卡 App 里加入学习。没有 Token 时先用 Skill 目录 `.env`，再问 `MAIMEMO_TOKEN`（在 https://www.markji.com/ 获取）。
