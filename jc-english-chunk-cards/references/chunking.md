# 切块规则

先读整句，再按**语义块**切开。一块是母语者一次扫过去的单位，不是单词，也不是语法成分名。

## 怎么切

- 一块大约 2–8 个词：动词搭配、介词目的、时间、对象。
- `for + 事` = 目的，不是「给谁」。`for spaced review` 是一块。
- `into + 结果` = 变成什么样 / 写进哪里。`write into`、`extract A into B` 整块记。
- `what …` 带着后面整段 = 「那件事/那些东西」，读到 what 就知道还没说完。
- `support doing`、`in my spare time` 这类也整块记。

## 顺序

从左到右往下加信息：动作 → 目的/对象/时间。英文常把目的、时间、对象接在后面，这是常态，不是让读者倒回去从句尾读，也不用标主谓宾。

## 用词

- 正面英文用美国人会说的话；材料是中文时先译成口语，再切。
- 学习圈词可以留在正面（用户在 App 里会碰到），背面必须给日常替换：
  - spaced review → go over my cards / quiz myself / review a bit every day
  - write into → add to / put in
  - extract → pull out / grab
  - semantic chunks → phrases
  - notepad（墨墨词本）→ list / vocab list
- 生词只列预估四级以上的词；变体写成 `chats ← chat`。
