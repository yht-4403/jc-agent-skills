# 抽哪些句子

从知识库、日常思考、过往文案或对话里抽句时读这份。用户已经贴好要制卡的原句时不读，有几句做几张。

## 张数怎么定

不要用固定张数。先定一个主题，再判断把这件事讲完需要多少句会说出口的话，按这个深度一次出完。

停的标准是这条开口链已经连贯：听的人能顺着听完，中间没有跳步。材料只撑得起短链就短，讲个人项目、商业判断、自我介绍、过往经历这种要讲清来龙去脉的，就把链补全。不要跨主题凑，也不要在能讲完之后继续堆金句。

用户点名张数就按点名的来。说「再来一批」时，同一主题接着补还没练到的环节，跳过已经写过的整句。

制卡前先报主题、这条链覆盖哪些环节、为什么这些句够（或还缺哪一截）。

## 默认一个主题

未指定时，从材料里只选最值得练的一个主题。三类里挑一个，或更细的一条链：

| 主题 | 抽什么 |
| --- | --- |
| 和外国人商务洽谈 | 开口、摸需求、找关键人、报价前、跟进、把事说清楚 |
| 企业面试 | 商业思考、自我介绍、过往经历怎么讲 |
| 日常使用 | 约时间、打招呼、把话说成人话、通勤和聊天 |

用户点名只要一类，或更细（「讲个人项目」「面试自我介绍」），整批按该类。只有用户明确说要混合时，才拆成多主题。

## 要 / 不要

要：当面、电话、面试、商务消息里会说或会听到的整句。中文先译成美国人会说的话。按说话顺序排：开口 → 展开 → 收口，相邻两张能接上。

不要：Token、路径、Skill 名；本轮已写过的整句；改简历条目、投递策略（那是简历类技能）；译出来也不会说出口的流程备忘。
