# 原子批次任务

读取指定文本块、必要上下文、当前地图和已有原子。先理解作者在讨论什么问题，再提炼可复用的定义、原则、判断、动作、案例、反例和边界。

要求：

1. 保留完整语义，不把有条件的知识压成口号。
2. verified 原子保存 source_id、chunk_id、原始行号和最短充分证据。
3. 原文没有的推论标记 inferred；二次整理稿不能代替原文。
4. 核心方法需要足够解释，简单事实和案例不必机械填写概念四问。
5. 与已有内容重复时合并证据，条件不同或观点冲突时分别保留。
6. 输出后运行 `validate-atoms` 与 `coverage`。

批次报告说明：处理范围、重要新增方法、代表案例、冲突或低置信度内容，以及它们是否改变了地图或 Skill 划分。
