## 推荐学习顺序（从依赖关系推出）

```
<cap-a>  ──depends-on──>  <cap-b>
   │
   └──composes-with──>     <cap-c>
```

1. 先读 `<cap-b>`（它是 `<cap-a>` 的前提）
2. 再读 `<cap-a>`
3. 与其他能力配合时见 `<cap-c>`
