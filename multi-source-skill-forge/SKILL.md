# 炼技 SkillForge — 把长内容熔炼成可调用的 Skills

把一份或几份高价值内容里**可迁移的方法论**，熔炼成一组原子化、可被 agent 在真实场景中调用、可组合、可压力测试的 skills。

**它不做**：摘要、读书笔记、读后感、金句集、人设模仿。
**它做**：把一个判断框架变成一张有触发条件、有执行步骤、有判停边界的能力卡。

> 方法论血统（如实标注）：八阶流程建立在 **RIA-TV++** 之上 —— Adler《如何阅读一本书》的分析阅读、
> 赵周《这样读书就够了》的 RIA 便签拆书法、nuwa-skill 的三重验证、Zettelkasten 原子化链接。
> 本 skill 在此基础上做了四项扩展：**多源三角、置信度分层、时效分层、争议卡**。详见 `references/pipeline.md`。

---

## 一、熔炼八阶

| 阶 | 名称 | 做什么 | 产出 |
|---|---|---|---|
| 0 | **定盘** | 确认使用者画像、材料清单、入口预算 | `CHARTER.md` |
| 1 | **通读** | Adler 四步真正读懂材料（结构/解释/批判/应用） | `OVERVIEW.md` |
| 2 | **抽丝** | 5 路独立提取器并行扫描，只收集不筛选 | `candidates/*.md` |
| 3 | **三角** | 四重验证 + 跨源三角矩阵 + 置信度分级 + 争议卡 + 晋级门 | `verified.md`、`rejected/`、`conflicts/` |
| 4 | **立卡** | 每个入选单元铸成 R/I/A1/A2/E/B 能力卡 | `capabilities/cards/*.md` + `bundle.yaml` |
| 5 | **织网** | 建立依赖/对比/组合关系，写共享术语表，回填 A2 | `GLOSSARY.md`、回填后的卡 |
| 6 | **试炼** | 独立盲测：触发精度 + 诱饵 + 跨能力混淆 + 边界反转 | `test-prompts.json`、`test-results.md` |
| 7 | **出炉** | 编译为 hub / split / mix，写 DIGEST，安装到 skills 目录 | `dist/`、`DIGEST.md` |

完整执行规范见 `references/pipeline.md`。**不要凭本表跳步**。

## 二、开工前必须先问的三个问题

用户没主动说清时，一次性问完再动手，不要边做边猜：

1. **源材料是什么？** 文件路径 / 链接 / 粘贴文本。**没有源文本就停下来要**，宁可等也不凭记忆编。
   - 要说明材料类型：书 / 长视频转写 / 播客 / 课程 / 访谈 / 系列长文 / 资料集。
   - 若用户想蒸馏视频但只有链接，先提示需要字幕或转写文本。
2. **你（使用者）是谁？打算拿它干什么？** 这一步直接决定提取优先级与能力粒度：
   - 你的角色与日常任务是什么？
   - 你最常处理什么材料 / 面对什么决策？
   - 这份内容里你最想解决的那一个问题是什么？
   - 有什么明确的**不要**（不关心的领域、不想被触发的场景）？
3. **你想要多少个"可直接调用"的入口？** 注意问的是**入口数**，不是内部能力数：
   - A. 1 个总入口，内部自动路由（`hub`）
   - B. 1 个总入口 + 2–4 个高频能力独立成入口（`mix`，推荐默认）
   - C. 全部独立成入口，不要总入口（`split`，仅当能力数 ≤ 5）

以及**深度选择**（可以替用户默认，但要告知）：

| 深度 | 适用 | 跑的阶 | 产出口径 |
|---|---|---|---|
| **速成** | 单篇长文、单期播客、20 分钟级视频 | 0→1→2→3→4→7 | 2–4 张能力卡，省略 A1 案例段，省略试炼 |
| **完整** | 整本书、系列课程、多期播客、≥3 份材料 | 全八阶 | 4–10 张能力卡，全字段，含试炼与回炉 |

用户没明说时：材料总字数 < 2 万或来源数 = 1 → 默认**速成**并主动说明省略了什么；否则默认**完整**，并提示这一步 token 成本较高、建议分会话执行（靠 `STATE.md` 断点续跑）。

## 三、核心不变量（任何迭代都不能违反）

1. **原子性** — 一张能力卡只做一个方法论单元。出现"和/与/以及"的标题通常是没切干净。
2. **可追溯** — 每条结论必须能指回具体出处（章节 / 页码 / 时间戳 / 分 P / 集数），且引用片段 ≤150 字（英文 ≤100 词）。
3. **可验证** — 每条能力必须通过四重验证；晋级入口必须通过试炼。
4. **证据分级，不混装** — 跨源一致（A）与单源单域（C）**不能使用同一语气**。C 级内容不得成为能力卡的核心主张，只能做 example 或标为待补证。
5. **冲突不被抹平** — 源与源之间真实的分歧必须产出争议卡，写清双方立场、各自证据和适用条件。不允许"综合考虑一下"。
6. **画像只调优先级，不扭曲原意** — 用户不关心的领域做**归档**（archived）而非删除；归档与"知识验证失败"是两件事，必须分开放。
7. **单一事实源** — 所有卡与元数据先落到 `bundle.yaml`，最终 skill 由它编译出来，不手工维护两份。
8. **可交付即终点** — 流程结束的标志是"用户能调用"：产物要么安装进 skills 目录，要么明确交付为可发布的仓库形态。
9. **原文本不外流** — 不把电子书原文、用户私有材料提交到公开仓库；对外发布只带短引用与自制产物。

## 四、必须停下来与用户确认的四个点

| 时机 | 确认什么 |
|---|---|
| 开工前 | 三个问题（材料 / 画像 / 入口数）＋深度档位 |
| 通读后、抽丝前 | 展示 `OVERVIEW.md` 骨架，特别是**批判段**（作者局限），确认"读出来的确实是这本书" |
| 三角后、立卡前 | 展示入选名单与置信度分级：`A 级 N 条 / B 级 M 条 / C 级 K 条 / 归档 J 条 / 淘汰 R 条`，问一句"有想捞回或砍掉的吗" |
| 出炉前 | 展示编译形态建议（hub/split/mix）与入口清单，确认后再写盘 |

第 3 个确认点成本最低、收益最大 —— 立卡与试炼是全流程最耗时的部分，在这里对齐能省掉大量返工。

## 五、产出目录结构

在用户可写的工作目录下建 `forge/<slug>/`：

```
forge/<slug>/
├── STATE.md                  # 断点续跑：当前阶 + 各能力进度 + 下一步
├── CHARTER.md                # 阶 0：材料清单 + 使用者画像 + 入口预算
├── OVERVIEW.md               # 阶 1：Adler 四步（含批判段）
├── candidates/               # 阶 2：原始候选池（审计用，不筛选）
│   ├── frameworks.md
│   ├── principles.md
│   ├── cases.md
│   ├── counter-examples.md
│   └── glossary.md
├── verified.md               # 阶 3：入选单元 + 四重验证 + 三角矩阵 + 置信度
├── rejected/                 # 阶 3：淘汰与归档（必须写明原因，可捞回）
├── conflicts/                # 阶 3：争议卡（源间真实分歧）
├── .forge/
│   ├── bundle.yaml           # 单一事实源：所有能力元数据
│   └── cards/<slug>.md       # 能力卡正文（R/I/A1/A2/E/B）
├── GLOSSARY.md               # 阶 5：跨源统一术语表
├── DIGEST.md                 # 阶 7：面向人类读者的精华长文
└── dist/<slug>/              # 阶 7：编译产物
    ├── <hub-name>/SKILL.md   #   hub 入口（含路由表）
    └── <cap-slug>/SKILL.md   #   晋级的独立入口
```

## 六、常见失败模式（速查，完整版见 `references/failure-library.md`）

| 症状 | 根因 | 修法 |
|---|---|---|
| 读起来像书摘 | 阶 4 的 I 段在抄原文 | 用"对一个没读过原书的人，这段能不能让他明白这个方法在做什么"自检 |
| skill 从不被触发 | A2 触发描述太宽（"需要思考时"） | 必须写**可识别的语言信号**，中英双写关键词 |
| skill 被滥触发 | 缺 B 边界段 | 补反场景 + 作者警告的失败模式 |
| 一本书拆出十几个入口 | 没跑晋级门 | 未晋级的能力保留为"路由入口内的能力卡"，不是删掉 |
| 同材料内两个 skill 互抢 | 没做跨能力混淆测试 | 诱饵里必须至少 1 条"该触发兄弟 skill"的题 |
| 多源材料被当成单源处理 | 跳过三角矩阵 | 每条结论标注它出现在哪几个源，判断是否**独立**表述 |
| 把转引当独立证据 | 来源互相抄 | 检查是否有一方明确引用另一方；转引降级为同一证据 |
| 输出一堆没人要的能力 | 画像没问 | 阶 0 三问不能省 |
