## 官方参考与适用边界

- [Semi DSM 全局 Token](https://semi.design/dsm_manual/zh-CN/web/globalToken)：输入基准色可按算法生成十个色阶；字体排版支持倍数和自定义方式，文档建议字号倍数 1.15–1.333。它也支持间距、圆角和阴影配置。算法推荐仍需结合页面任务检验。
- [Semi Design Tokens](https://semi.design/zh-CN/basic/tokens)：基础色与功能角色分开，组件引用设计变量，便于统一变更主题和状态。
- [Arco Palette](https://arco.design/palette/list)：另一个色板工具候选；不能因为同为设计系统，就把两家的算法当成同一套。

## 在项目里怎样固定

先查已有规范和 Token。没有时，从当前原型提取最小可用集合：

| 对象 | 要固定的内容 | 检查方式 |
| --- | --- | --- |
| 颜色 | 基准色、中性色阶、文字、表面、状态与操作色；各交互状态映射 | 在实际背景上测对比度，检查状态语义和真实截图 |
| 字体与字号 | 中英文字体及回退、正文基准、有限字号层级、字重和行高 | 检查中文、数字、长标题和窄屏；等比字阶可用“基准字号 × 倍率ⁿ”作为通用探索方法，这不是已核实的 Semi 内部实现公式 |
| 间距与尺寸 | 选定的基础网格、控件高度、容器宽度、圆角和阴影 | 检查密度、对齐、触控和不同视口；4/8 网格是可选方法，沿用项目已有规则 |
| 组件 | 按钮、输入、筛选、卡片、弹层等外观、状态及行为 | 操作默认、焦点、加载、禁用和失败态，避免只固定静态外观 |

优先把原型取值收进统一变量，再让公共组件引用语义或组件角色。只在当前规模确有收益时增加 JSON 生成 CSS 的脚本，不为简易项目搭建额外工具链。数学计算帮助控制一致性，页面是否好看、任务是否顺畅仍由截图与真实交互检验。
