# 阶段推演与信号清单

用途：给一家公司定阶段，并说明依据。阶段判断错了，后面选维度和提炼结论都会失焦。

## 为什么阶段推演是这套方法的核心

同一家公司，在不同阶段要的东西完全不一样：

| 阶段 | 它看到你时在想什么 |
|---|---|
| 起盘 | 你能不能一个人把事做出来 |
| 抢占 | 你能不能跟上速度、别拖后腿 |
| 经营 | 你能不能把投入产出算清楚 |
| 转型 | 你能不能带来新的可能性 |

所以"为什么它那时考核这个"这个问题，答案不在岗位本身，在公司阶段。面试、见客户、提案都适用同一逻辑：

```
公司阶段 → 最缺什么 → 所以它现在要什么 → 所以我要证明/验证什么
```

## 四个阶段的识别信号

### 起盘

**信号**：成立时间短或新业务刚立项；融资轮次早；团队规模小、一人多岗；公开信息少；产品或服务还在打磨；招聘要求宽、JD 写得模糊。

**最缺**：把概念变成能交付的东西。

**调研重点**：团队背景与履历、产品可行性、钱能烧多久、有没有跑通的早期案例。

**风险提示**：招聘要求写得特别宽，可能意味着职责不清；"从 0 到 1"经常同时意味着没有流程、没有资源、没人带。

### 抢占

**信号**：有产品在跑、增长快；招聘猛、岗位多、开价有竞争力；融资顺利或有明确收入增长；公开报道多、口碑活跃；开始强调组织和流程。

**最缺**：跑赢对手、占住位置。

**调研重点**：竞争格局里它排第几、增长质量（是真需求还是补贴堆的）、组织能力跟不跟得上、主要对手在做什么。

**风险提示**：增长快的公司内部常常很乱。要分清"业务顺"和"组织顺"，这两件事经常不同步。

### 经营

**信号**：增长放缓或停止；开始抓利润、效率、人效；招聘从扩张变成补缺，要求变细变专；出现品类收缩、产品线下架、渠道优化；对外口径从"增长"转向"健康"。

**最缺**：投入产出比。

**调研重点**：成本结构、品类或产品线健康度、渠道效率、哪些业务在被放弃。

**风险提示**：这个阶段进来的岗位，考核指标通常偏硬（利润、效率、ROI）。要问清楚指标口径和基线。

### 转型 / 守成

**信号**：主业见顶或下滑；换方向、砍业务、组织调整；核心人员流动；对外叙事改变（从"做产品"变成"做平台/AI/第二曲线"）。

**最缺**：找到第二曲线，或保住基本盘。

**调研重点**：主业真实状况（不是它说的）、新方向投入多大、组织调整的力度、老业务的现金流还能撑多久。

**风险提示**：转型期公司的岗位风险最高。要问清新业务有没有独立预算、有没有一号位、做不成会怎样。

## 信号不够怎么办

不要凭感觉贴标签。用这张表把公开信号转成阶段判断：

| 你查到的 | 指向 |
|---|---|
| 大量岗位在招同职能多人 | 抢占期扩张，或经营期补缺（看是否新增业务线） |
| 招聘要求宽泛、职责不清 | 起盘期 |
| 招聘要求细、偏成本与效率 | 经营期 |
| 融资新闻集中在早期轮次 | 起盘期 |
| 财报或报道从讲增长转为讲利润 | 经营期 |
| 出现裁员、业务剥离、组织架构调整 | 转型或守成 |
| 高管密集变动 | 转型或经营承压 |
| 对外叙事突然换了关键词 | 转型（注意区分真转型和换故事） |
| 渠道从多平台收缩到单一平台 | 经营期收缩 |
| 新产品线独立立项、独立团队 | 转型或第二曲线尝试 |

**证据不足时允许这样写**："从公开信号看更像是经营期，依据是 X 和 Y，但缺少 Z 这一项，还不能完全确定。"

这比硬贴一个标签可信得多，而且在面试或谈判桌上是一个能接住追问的回答。

## 阶段推演的最终产物

一句话，格式是：

> "这家公司现在处在 ____ 阶段，依据是 ____ 和 ____，所以它现在最缺的是 ____，因此这次我要重点证明/验证 ____。"

这句话写不出来，说明 Step 2 没做完，不要往 Step 3 走。
