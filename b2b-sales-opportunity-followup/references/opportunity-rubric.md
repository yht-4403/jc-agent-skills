# 商机六要素评估标准

每项使用三档状态：

- 明确：有客户侧直接证据，且能支持下一步决策；
- 部分明确：存在相关线索，但关键细节、角色或承诺尚未确认；
- 缺失：沟通记录中没有可靠信息，或只有我方假设。

| 要素 | 需要确认的内容 | 常见风险信号 |
|---|---|---|
| 业务目标与痛点 | 客户想改变什么、当前影响、优先级、成功指标 | 只有功能兴趣，没有业务影响或优先级 |
| 决策角色与影响关系 | 使用者、推动者、决策者、预算负责人、反对者 | 只接触单一联系人，关键人未参与 |
| 决策标准与流程 | 评价维度、对比方式、审批与采购步骤 | 不知道如何选、谁批准、何时批准 |
| 预算与采购条件 | 预算来源、区间、付款、招采、法务和安全要求 | 价格被反复追问但没有预算与价值讨论 |
| 时间与紧迫事件 | 目标上线时间、倒排节点、延迟后果 | 时间表只来自销售方，没有客户业务事件 |
| 竞争与双方承诺 | 竞品、现状方案、客户下一步、我方交付 | 只有我方发送材料，没有客户行动承诺 |

## 置信度

- 高：客户原话或明确书面材料直接支持；
- 中：多条线索一致，但仍需确认；
- 低：主要来自销售推断或信息明显不足。

禁止仅凭积极语气、会议时长或“回去研究”判断高成交概率。
