# 文案规则

读者默认是已经决定使用产品的人，不是第一次听说它的访客。登录后的页面不是营销页。

## 术语

- 统一用：
- 不要混用：

## 场景

| 页面 | 场景 | 主行动 |
|---|---|---|
| | 产品界面 / ToC 转化 / ToB 方案 / 定价 | |

## 预算

- 产品界面：页副标题 0；日常页完整说明句 0
- 空态 / 错误 / 不可逆：各 1 句
- 官网英雄区：1 个标题，最多 1 句副标题，1 个主按钮

## 禁区

- 欢迎语、功能卖点、节标题下的介绍段
- 空转词：轻松、高效、赋能、重塑、无缝、新范式、无限可能
- 未提供证据的用户量、百分比、客户名

## 删字测试

去掉所有非对象 / 非动作 / 非状态 / 非数据的句子后，主路径仍须可完成。
