# 场景预算

写或改之前读本文件。读完必须标出一个主场景，并按该场景的预算工作。不读会把官网结构写进产品界面，或把产品界面的哑巴稿当成转化页。

这些公式来自对转化页和产品界面的拆解，是工作原则，不是保证转化率的定律。学结构，不抄原句。

## 如何选场景

| 读者此刻在做什么 | 主场景 |
|---|---|
| 已经进入产品，要开始说话或点下一步 | 产品界面 |
| 个人用户还没动手，要不要现在用 | ToC 转化 |
| 评估者/采购在判断值不值得试用或咨询 | ToB 方案 |
| 已决定用，在选哪一档 | 定价 |
| 想弄清某一项能力是不是自己要的 | 功能块 |
| 在查规则、权限、计费、加入与退出 | 规则/FAQ |

一个页面可以有次要区块，但主场景只能有一个。登录后的壳默认是产品界面。

## 产品界面

含：对话台、工作台、列表、详情、设置、空态、错误、确认。

**任务：** 让人完成当前这件事。

**允许：** 对象名、动作（动词+对象）、状态、数据、不可逆后果。

**禁止：** 欢迎语、产品介绍、功能卖点、页副标题、卡片里复述标题的段落、按钮旁的解释。

**预算：**

- 页面标题：对象名，2–8 字
- 页副标题：0
- 主按钮：1 个，动词+对象
- 日常页完整说明句：0
- 空态：1 句现状 + 1 个动作
- 错误：发生了什么 + 怎么处理
- 不可逆确认：对象 + 会失去什么

**句式：** 祈使、名词、省略主语。输入框可以是邀请开口的残句，不要价值主张。

**学：** 对话台几乎不说话；设置和权限学 FAQ 的条件句。

**反例：** 「欢迎来到你的工作台，在这里管理所有项目，让团队保持同步。」

## ToC 转化

含：未登录首页英雄区、个人产品下载/注册页。

**任务：** 让个人立刻做一个低成本动作。

**公式：** 要做的事 + 谁帮你 + 可感知的时限或步骤 + 主按钮说出得到什么。

**预算：**

- 标题：一件事，尽量能读出结果
- 副标题：最多 1 句，补范围或对象，不补愿景
- 主按钮：1 个；下载、生成、开始某件具体事
- 英雄区不要功能清单

**证明：** 只用用户提供的数字、时限、模板量、用户量。没有数字就用演示或具体动作，不写「深受欢迎」。

**学：** 任务、时限、立刻行动；先演示交付物再解释。不学重复的 SEO 模板描述，不学「真智能真好用」。

## ToB 方案

含：企业产品官网、申请试用、Demo、购买咨询。

**任务：** 让评估者相信「懂我们的流程」，并申请试用或咨询。

**公式：** 组织结果 + 痛点问句或具体机制 + 证明 + 试用/咨询。

**预算：**

- 标题：组织能少打什么工，或流程从哪到哪
- 副标题：1 句机制，不写新范式、倍增、无限可能
- 主按钮：申请试用 / 获取 Demo / 开通企业版；需要销售跟进时才用咨询
- 功能区：每块只讲一件事
- 证明区：客户、可检查数字、或可演示的步骤；没有证据就删掉本区

**学：** 痛点问句、社会证明、试用双按钮、演示里的「步骤+完成态」。不学赋能、重塑、效率倍增。

**演示区文案** 按产品界面写：步骤、对象、完成态。周围营销句按 ToB 写。不要反过来。

## 定价

**任务：** 帮人选档，不是再介绍产品。

**公式：** 这档给谁 + 价格 + 可数额度 + 年付如何更省（若真实存在）。

**预算：**

- 档位名 + 一句身份标签（日常 / 高频 / 团队）
- 列表只放可数项：次数、人数、容量、坐席
- 0 段产品介绍
- ToB 定价旁可以有销售入口；ToC 定价以自助开通为主

**学：** 「偶尔做 PPT 用这一档」这种推荐句。不学套餐卡上的愿景收束。

## 功能块

嵌在官网中的能力说明，不是登录后的功能本身。

**公式：** 标题是一件用户能认出的事；正文只补一个结果或一个机制。

**预算：** 标题 ≤ 16 字；正文 1 句；不要标题下再写一段复述。

同一页功能块不要重复同一个承诺。做不到具体就删这块，改为演示或定价。

## 规则 / FAQ

含：计费、席位、权限、加入退出、数据是否用于训练。

**公式：** 条件 + 结果。可以有时间、数量、角色。

**预算：** 问句用读者的话；答句可检查，不写态度。

产品界面的设置说明、权限提示、空态补句，优先用这个场景，不用 ToC/ToB 英雄区。
