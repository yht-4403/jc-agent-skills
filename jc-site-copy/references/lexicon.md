# 空转词

写完或改完后读本文件做一遍扫描。不读会留下「删掉也不改变任务」的词。这些词可以出现在用户原话里，不要写进界面或官网正文，除非立刻跟上可检查的对象、时限、次数或后果。

本表是家规，不是语言学定理。目标是让每句话做工：改变行动、范围或验收。

## 默认删除

删掉后句子仍成立，就删：

轻松、高效、全面、专业、智能、无缝、完美、快速、灵活、强大、卓越、真正、深度、精准、一站式、一体化、数智化

赋能、助力、重塑、驱动、打造、释放、升级、重构、颠覆、引领

新范式、新体验、无限可能、好搭子、全场景、新一代、最佳实践

了解更多、立即开启、开启新体验、免费开始无限可能、点击这里

## 替换方向

| 空 | 改成 |
|---|---|
| 轻松完成 | 时限、步数，或直接让按钮完成那件事 |
| 大幅提效 | 用户提供的前后对比；没有就写少了哪一步 |
| 无缝连接 | 连上哪些具体工具或数据 |
| 赋能团队 | 隔离、席位、权限、定时任务里的一件 |
| 重塑管理 | 从记录到哪一个可检查的动作 |
| 强大的 AI 助手 | 删。对话台用邀请开口的残句 |
| 在这里管理你的… | 删。标题用对象名 |
| 了解更多 | 看定价 / 申请试用 / 查看项目 |

## 检查三问

1. 这个词删掉后，用户要做的事变了吗？没变就删。
2. 能否换成对象、动作、数字、完成态？能就换。
3. 数字或客户名是用户给的吗？不是就不要写证明句。

## 允许留下的完整句

只在这些位置允许完整说明句：

- 空态：还没有 X。创建第一个 X。
- 错误：没保存。检查网络后重试。
- 不可逆：删除「名称」？不可恢复。
- 非直观字段：用于发票，不会公开。
- FAQ / 计费规则：条件句。

日常列表、导航、卡片、对话台首屏，不因为「更友好」而使用上述完整句以外的说明。
