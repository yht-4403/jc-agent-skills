# 视频文案教学化

适用于把"视频转文字"得到的口播稿、字幕原文，提炼成可以发布的教学文章。

## 目标

把碎片化、口语化、可能有错字的视频原文，整理成一篇结构清晰、有方法论支撑、能让读者产生行动冲动的教学文章。

## 处理顺序（不能颠倒）

```
脱敏 → 辨义 → 提炼 → 引用 → 组织 → 取标题
```

任何一步没做完，不要进入下一步。尤其是"脱敏"必须最先做，否则敏感内容会污染后续所有提炼。

## 第一步：脱敏（最先做）

**目标**：在总结之前，先把不能留下的内容删干净。

### 必须删除或脱敏的内容

| 类别 | 处理方式 |
| --- | --- |
| 个人隐私（手机号、身份证、住址、工作单位、家庭信息） | 用 `***` 替换或整段删除 |
| 政治敏感（具体政治人物、政策评价、地区敏感话题） | 整段删除 |
| 法律风险（诽谤、人身攻击、未证实的指控、违法操作教程） | 整段删除 |
| 商业机密（未公开数据、未发布产品、客户内部信息） | 整段删除 |
| 不当言论（性别/地域/职业歧视、攻击性言论） | 整段删除 |
| 未经核实的他人隐私（讲到具体某人某事时） | 删除可识别身份的细节 |

### 脱敏自检

完成脱敏后回答一遍：

- 这篇文章如果被截图传播，会让谁陷入麻烦？
- 里面有没有任何"具体到能被对号入座"的人/事/数据？
- 有没有可能被认定为侵权、诽谤、违规的内容？

任何一项答"有"，回去继续删。

## 第二步：辨义（修正视频转文字错误）

视频转文字常见错误模式：

| 错误类型 | 示例 |
| --- | --- |
| 同音字 | "市值" ↔ "事实"，"机器" ↔ "计较"，"在" ↔ "再" |
| 专有名词识别错 | 人名、品牌名、技术术语被听成普通词 |
| 断句错误 | 长句被切成两半导致句意不通 |
| 口头重复 | "这个这个"、"就是说就是说" |
| 语气词残留 | "嗯"、"啊"、"那个"、"就是" |
| 数字识别错 | "一万" ↔ "1 万" ↔ "100 个"|

### 辨义规则

- **能根据上下文确定的，直接修正**，不保留错误。
- **拿不准的术语**，标注 `[原文：xxx，疑为：yyy]`，让用户最终确认。
- **重复表达和语气词**，全部删除。
- **不要替原作者添加观点**，只在原意范围内修正用词。

## 第三步：提炼核心要点

提炼时区分四种不同的信息层级，避免把"金句"和"案例"混为一谈：

| 层级 | 是什么 | 处理方式 |
| --- | --- | --- |
| 核心论点 | 整段视频想让人记住的那 1-3 句话 | 必须放进文章主结构 |
| 方法论 | 可复用的步骤、判断标准、模型 | 整理成清单或流程 |
| 案例/例子 | 用来论证观点的具体故事或数字 | 至少保留 1 个最典型的 |
| 金句 | 适合直接引用的原话 | 用 `>` 块引用 |

**取舍标准**：如果一个段落删掉之后，文章核心论点不受影响，就删。教学文章不是"原文压缩"，而是"原文精华重组"。

## 第四步：引用原文

引用是为了**保留原作者的语言力量**，不是为了凑字数。

### 引用规则

- 每篇教学文章引用原文 **3-5 处**，多了显得啰嗦。
- 选择标准：**短、狠、有判断**。能用 1 句不用 3 句。
- 引用必须忠于原文（已脱敏、已辨义之后的原文），不能改写。
- 用 Markdown 块引用：

```markdown
> "原作者的原话，不超过两句。"
```

- 引用后紧跟一段自己的解释或延伸，不要让引用孤立存在。

## 第五步：组织教学结构

教学文章 ≠ 方法论笔记。教学文章要面向不熟悉这个话题的陌生读者，**起承转合不能少**。

### 推荐结构

```markdown
# {抓住人性的标题}
#{标签}
> {一句话钩子：读者打开这篇能拿到什么}

## 开场：制造共鸣或反差

{用一个场景、一个反常识、一个痛点开场，让读者觉得"这就是在说我"}

## 核心观点

{这篇文章想让读者记住的核心判断，1-3 条}

> "{选一句最有力的原文引用}"

## 为什么是这样：原理 / 论证

{用案例、数据、对比解释为什么核心观点成立}

## 怎么做：方法论 / 步骤

### 第一步：{动作}
{怎么做，做对的标志是什么}

### 第二步：{动作}
{怎么做，做对的标志是什么}

### 第三步：{动作}
{怎么做，做对的标志是什么}

## 常见误区 / 反面案例（如有）

- {误区 → 为什么错 → 正确做法}

## 关键收获

{用一句有判断力的话收尾，回扣开场}

> "{再引一句原文金句作为余韵}"
```

### 写作规则

- **第一段必须勾住人**：用场景、反共识、痛点，避免"今天我们来聊聊…"这类温吞开场。
- **方法论必须可执行**：写"第一步做 X，做对的标志是 Y"，不要写"建议你重视 X"。
- **保留原作者的语气**：如果原作者风格犀利，不要改成温吞；如果原作者克制，不要强行加感叹号。
- **删除"视频里说"的痕迹**：不要写"博主提到"、"视频中讲到"，直接把观点变成文章的主张。
- **每一段都要有信息增量**：删掉过渡句、客套话、AI 腔（"总而言之"、"综上所述"）。

## 第六步：生成抓住人性的标题

标题决定打开率。一个抓住人性的标题，本质是**在读者大脑里制造一个未闭合的认知缺口**。

### 抓住人性的常用模式

| 模式 | 公式 | 示例 |
| --- | --- | --- |
| 反认知 | `你以为的{X}，其实是{Y}` | 你以为的努力，其实是假装在努力 |
| 损失警示 | `不{做X}，你会失去{Y}` | 不会拒绝的人，最后都被生活拒绝 |
| 揭秘式 | `为什么{反常现象}？因为{反直觉真相}` | 为什么越努力越穷？因为你在用战术勤奋掩盖战略懒惰 |
| 反共识 | `别再{常见错误}了：{正确做法}` | 别再背单词了：英语好的人都在做这件事 |
| 身份锚定 | `{身份/人群}必须知道的{洞见}` | 30 岁前没存到钱的人，都忽略了这一点 |
| 数字承诺 | `{N}个{X}，让你{结果}` | 3 个面试技巧，让你拿到比同龄人高 50% 的薪资 |
| 对比反差 | `为什么{A}比{B}更{重要/赚}` | 为什么副业比主业更值得投入 |
| 提问钩子 | `{反直觉问题}？答案让你{反应}` | 月薪 3 万的人为什么还焦虑？答案出乎所有人意料 |
| 警示式 | `警惕：{现象}正在让你{严重后果}` | 警惕：这种"努力"正在毁掉你的下一个 10 年 |

### 标题自检

写完标题后回答：

1. **读者点开的理由是什么？**（具体到一种情绪：好奇、焦虑、嫉妒、不甘、共鸣）
2. **承诺的内容文章里真的有吗？**（不能用标题党骗点击）
3. **标题里有没有具体的"钩"？**（数字、身份、反差、损失，至少占一个）
4. **如果只看标题不看内容，读者能不能猜对结论？**（如果能猜对，标题没价值；要让人猜不出结论但很想知道）

### 标题红线

- ❌ 不要全靠"震惊"、"必看"这种空洞强调词
- ❌ 不要承诺无法兑现的结果（"看完月入十万"）
- ❌ 不要用攻击性、歧视性、地域黑标题
- ❌ 不要用"XX 方法论"、"XX 总结"、"XX 复盘"这种分类式标题（参考 `naming.md`）

## 输出最终文章前的检查清单

- [ ] 敏感内容已经全部删除或脱敏
- [ ] 视频转文字的明显错字已修正，拿不准的已标注
- [ ] 核心观点不超过 3 条，且能用一句话表达
- [ ] 至少保留了 1 个具体案例或数字
- [ ] 原文引用 3-5 处，每处都短而有力
- [ ] 方法论部分写的是"怎么做"，不是"为什么重要"
- [ ] 标题至少符合一种"抓住人性"的公式
- [ ] 没有"博主提到"、"视频中说"这类痕迹
- [ ] 没有 AI 腔和废话过渡句
