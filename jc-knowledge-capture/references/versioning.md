# 版本管理

适用于用户要求备份、存版本、管理版本或回滚文档。

## 命名约定

沿用当前知识库已有的 Docker 式“最新版本”机制。注意：当前约定拼写为 `lastest`，为了兼容已有文档，继续保留这个拼写。

```text
文档名-lastest.md
文档名-v1.md
文档名-v2.md
```

`-lastest.md` 是最新工作版本。`-vN.md` 是历史备份，创建后不再修改。

## 备份流程

1. 找到当前的 `文档名-lastest.md`。
2. 在同目录查找已有的 `文档名-vN.md` 文件。
3. 新版本号 = 当前最大 N + 1。
4. 将 `文档名-lastest.md` 内容复制到 `文档名-v{N}.md`。
5. 后续继续编辑 `文档名-lastest.md`。

## 回滚流程

1. 找到用户指定的 `文档名-vN.md`。
2. 将它的内容复制到 `文档名-lastest.md`。
3. 除非用户明确要求，否则不要删除更新版本的备份。

## 规则

- 版本号只增不减。
- 备份文件创建后视为不可变。
- 如果没有 `-lastest.md`，先询问是否要用当前文档创建一个最新版本文件。
