# 社交稿的表达目的与句式约束

朋友圈、小红书、公众号等直述体社交稿的默认版与 v2 共用本规则。适用于新写和用户授权改写的公开内容；忠实保存、只修格式、直接引语和技术契约沿用各自规则。

## 先确定读者要理解什么

动笔前从已有材料判断：读者看完要理解哪件事，或能做出哪个具体判断。材料足够时直接写，不增加固定问卷。

每段围绕这个目的推进，用事实、原因、动作、例子和适用条件帮助读者看懂。不要为了显得深刻、塑造权威或模仿某个人，额外添加反转、金句和口号。真实的情绪、个人位置和表达习惯可以保留，不要求所有内容都写成教程。

## 呈现事情，少预设读者犯错

直接说明发生了什么、为什么、在什么条件下成立。默认不写“你可能以为”“你一直搞错了”“很多人根本不懂”这类预判读者错误的开头。

用户材料确实提出了一个误解时，说明具体说法、事实依据和适用范围，不扩大成对读者群体的否定。

## 六类句式默认不用来制造反转

新写或改写社交稿时，默认不用以下句式及其近似变体制造对抗、纠错姿态或空泛强调：

- 不是……而是……
- 不在于……在于……
- 不需要……需要……
- 不会……会……
- 真正的……是……
- 与其说……不如说……

不能只把“不是”换成“并非”，或轮换句型规避限制。优先直接陈述有效信息，不额外设置一个材料里没有的错误观点来衬托结论。“本质是”“底层逻辑是”也不能代替解释。

## 用什么替代

| 要表达什么 | 优先写法 |
| --- | --- |
| 结论 | 直接说明对象和判断 |
| 原因或机制 | 交代谁做了什么，以及怎样影响结果 |
| 条件和边界 | 写清在什么情况下成立、哪些情况需要另外判断 |
| 下一步 | 写具体动作，以及动作要解决的问题 |
| 两种情况的差异 | 给出具体对象、行为或结果，必要时并列比较 |

例如，“真正的学习不是记住概念，而是建立认知框架”可以改成：“学完一个概念，可以换一个案例检查自己能否解释其中的变化。能独立作出判断，才有依据说自己理解了。”这是示范改写，不能当成用户经历或研究结论。

改写后要保留原有事实、逻辑、否定关系和限定，不能为了避开句型改变含义。材料不足时删掉空泛强调，不编造案例、数字或因果来填补。

## 可以保留的例外

- 用户要求忠实保留原话、明确模仿某段文风或采用其他风格时，按本次要求执行。
- 引用原文或分析句式本身时，保留所需句式。
- 对比承载准确性所必需的排除、纠错或边界时，可以保留。例如“这笔款项是退款，不是新增收入”说明了具体分类，不必强改。

例外以信息价值判断，不用固定次数配额。多个事实对比确有必要时可以共存；只为语气有力而设置的对立应改写。

## 交付前检查

- 每段是否在帮助读者理解具体事情，是否有仅为包装而添加的句子？
- 是否预设读者犯错，或凭空设置一个错误观点再纠正？
- 六类句式及近似变体是否用于制造反转；保留的对比是否承担具体事实或边界？
- 替换后是否增加了有效解释，并保留原意、真实情绪和不确定性？
