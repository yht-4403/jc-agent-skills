# 口语化直述体社交发布 v2

适用于朋友圈、小红书、公众号短文和其他公开分享。目标不变：像一个人把事情想清楚以后，直接、自然、准确地说出来。

v2 相对 v1 只加三件事：判断要更密、句子要更干净、力度不能靠对抗句式硬造。不改成 dontbesilent 口吻，也不改成小红书爆款。

测稿时优先读这一份。默认发布仍可用 v1。

## 什么时候使用？

出现以下任一信号时使用：

- 用户明确说要发朋友圈、小红书、公众号或对外发布；
- 用户说“正常说话”“直接说”“陈述句就好”“不要之前的小红书文案”；
- 用户给出一组定义、法则、判断句或自然口语，要求沿用“这种文风”；
- 用户要求去掉“AI 说”“某某说”“思考过程”和问答痕迹，整理成一篇正常内容；
- 用户说“用直述体 v2”“测 v2 文风”。

如果用户明确指定广告、促销、强钩子、品牌腔或 DBS 原腔，服从本次明确要求，不强制使用直述体。

写作前必须读取共用的 `social-expression-rules.md`。v2 的句子密度和节奏规则叠加在其上，不覆盖六类句式的默认限制与例外。

## 这版明确不做

- 不模仿 dontbesilent：不追求刺痛、说教、金句收尾、略带不耐烦。
- 不套小红书心理触发器：不为停留去制造冲突、焦虑、反转或身份羞辱。
- 六类句式默认不用来制造反转；准确性所必需的事实对比按 `social-expression-rules.md` 判断，不按出现次数决定。
- 不平铺变无聊之后去加钩子。句子没吸引力，先把判断写准、写具体，不把包装补上去。

## 先做密度检查

动笔前只问一句：

> 把核心判断单独拿出来读，它本身有没有信息？读者知不知道你在主张什么？

如果单独拿出来像空话、正确的废话或鸡汤，不要写开场，不要提问，不要加“很多人不知道”。回到材料里找出真正的区分、代价、例子或边界，再写那一句。

平铺直叙吸不住人，优先当成**判断还不够清楚**，不当成**标题不够刺激**。

## 先选择结构密度

直述体不等于完全没有格式。先看材料里有几个真正独立的判断，再选择最小够用的结构。

### 轻量直述体

适用于一个核心观点、一个短故事或几段连续推导。直接用自然段展开，不为了“体系化”硬拆编号。

```text
核心判断。

原因或背景。

具体例子。

边界或当前结论。
```

### 结构化直述体

适用于材料里同时存在多个规则、冲突、条件、步骤或适用场景。使用一个直述标题、一小段总判断，再用中文编号组织正文。

```text
{直接表达核心判断的标题}

{一至两段说明这次在想什么，以及当前总判断。}

一、{第一个分判断}

{先说结论，再解释原因和例子。}

二、{第二个分判断}

{同上。}

三、{第三个分判断}

{同上。}

{用一至三句自然收束，不喊口号，不要求互动。}
```

每个编号标题本身就要表达一个判断，例如“背景相似有价值，但不能要求所有条件都一样”。不要写“第一点”“问题分析”“具体方法”这种无法单独理解的空标题。

同一节里确实有三个以上并列条件时，可以再使用 `1. 2. 3.` 的小清单。存在清晰先后关系时，可以使用箭头链路：

```text
找到当前能模仿的对标
→ 做出第一轮结果
→ 暴露能力缺口
→ 补能力
→ 切换更高阶段的对标
```

结构只负责让逻辑更容易看懂，不能替代内容。不要为了整齐制造七条规律，也不要把同一个意思拆成多个标题。

## 核心写法

### 先说判断，再解释

每一段先写这一段真正要说的结论，再补原因、例子或边界。不要先铺很长的背景，也不要用提问拖延答案。

常用结构：

```text
判断是什么。
为什么这样判断。
一个具体例子。
什么情况下不成立。
```

材料很短时只写前两层，不为了完整硬补例子和边界。

### 句子怎么写

- 一段只推进一个主要判断。
- 短句放结论，长句放机制、条件和例子。快慢交替，不要整篇同一长度。
- 需要强调时，把要被记住的词放到句尾。例如把「根本不存在“滤镜之下”的客观对象」改成「“滤镜之下”的客观对象根本不存在」。
- 能直说就直说。条件用“如果……就……”，边界用“这只适用于……”，下一步用动作句。
- 少用设问和反问。问题如果有用，改成正文里的判断或转折，不要用提问吊着不给答案。
- 感叹号默认不用。祈使句慎用，尤其不要“请你记住”“真相是”“你必须”。

### 以陈述句和判断句为主

优先使用自然的白话句式：

- `X 就是 Y。`
- `如果 X，那么 Y。`
- `做不到 X，就换一个能做到的路径。`
- `这适用于 X，不适用于 Y。`

六类句式的默认限制、替代写法和例外统一遵循 `social-expression-rules.md`。优先把区别写成具体事实、因果或条件；必要的排除和分类可以保留，不机械限制次数。“本质是”等概括后必须有具体解释。

### 口语化，但清理口语噪音

保留“这个事儿”“说白了”“换一个”“干了一段时间”这类自然表达。删除连续重复、无意义停顿和转录噪音，例如“那个那个”“然后然后”“其实就是说”。

口语化不等于故意粗糙，也不等于故意呛人。句子可以有长有短，态度清楚即可，不需要恨铁不成钢。

### 抽象观点必须落到具体对象

抽象概念后面补一个真实场景、动作或对比。优先使用材料里已有的例子，不凭空编故事、数字和经历。

好的类比要解释同一个机制。只是在外观上相似、逻辑上无关的例子不要使用。类比服务理解，不服务犀利感。

### 语气可以确定，事实不能虚构

已确认的判断可以直接写。材料只是个人经验、推测或阶段性理解时，要保留“我现在更倾向于”“在这个场景里”“大概率”等限定。

直述体追求清楚，不追求假装什么都确定。不要为了句子有力，把相关性写成因果，把个例写成规律，把偏好写成事实。

尤其不要用“99%”“必须”“唯一”“永远”把阶段性理解写成定律。材料里本来就有这些数字或强度时，可以保留，并写清范围。

## 默认不要出现什么？

除非用户明确要求，否则不要出现：

- “你有没有发现”“很多人都不知道”“今天给大家分享”“你可能以为”；
- “看到最后”“建议收藏”“关注我”“评论区告诉我”；
- 焦虑钩子、身份羞辱、夸张承诺和强行反转；
- 表情符号、密集感叹号、装饰性分隔线和话题标签；
- 为了像小红书而切成大量一句一段；
- “根据资料”“AI 认为”“接下来逐一回答”“思考过程”等生成痕迹；
- 把每句话都加工成对仗、押韵或可截图金句；
- 没有信息价值的开场、总结和鼓励；
- 诊断口吻：“你这个不是产品”“第一步立刻去做 X”。公开发布是陈述自己的判断，不是给读者开药。

如果观点依赖某位作者、研究或数据来源，保留必要归属。删除的是无意义的转述口吻，不是事实来源。

## 标题怎么写？

标题直接使用文章最核心的一句判断，让读者知道里面在讲什么。标题服务于识别和理解，不服务于制造点击焦虑。

写完标题再做一次密度检查：单独看这一句，是否已经是正文里最硬的判断。如果标题比正文更空、更冲或更像营销，重写标题，不重写钩子。

推荐：

- `找一个合适的对标，可以减少从零试错的成本`
- `找不到对标，本身就是一条信息`
- `职业对标可以从对方做过的具体步骤入手`

不默认写：

- `99% 的人都找错了对标`
- `别再傻傻提升自己了`
- `看完这篇彻底改变你的职业规划`
- `我悟了！原来普通人赚钱只要这一步`
- `为什么你越努力越穷`

用户已经给出一句自然、准确的标题时，优先沿用，不重新包装。

## 朋友圈和小红书怎么区分？

### 朋友圈

单一观点通常不强制加标题，直接从核心判断开始，用几个自然段讲完。材料包含多个独立判断时，使用结构化直述体：一个直接标题，加少量 `一、二、三` 中文编号。朋友圈优先使用纯文本可复制的结构，不依赖 Markdown 标题、复杂表格和装饰符号。

可以保留一点“我最近在想”“我现在的理解是”这样的个人位置，但不要写成日记流水账。

### 小红书

使用一个直接标题和正常正文。内容较长或包含多个独立判断时，优先采用结构化直述体；内容本身只有一个判断时，不要硬拆成“第一、第二、第三”。

不主动添加标签、表情符号、互动问题和关注引导。用户要求平台运营元素时再补。

同一份材料只有在用户明确要两个版本时，才分别输出朋友圈版和小红书版；不要自动重复生成。

## 整理聊天记录时怎么处理？

1. 删除提问者、回答者、AI、Skill 和检索过程留下的对话壳。
2. 把反复出现的内容合并成一个判断，不保留多轮重复回答。
3. 保留真正推动理解的问题，但改成正文中的自然转折或小标题。
4. 引语只在原话本身不可替代时保留；普通观点直接改写成作者自己的陈述。
5. 删除“官方定义”“知识库中有大量资料”等无法增加内容价值的说明。
6. 不把聊天里暂时形成的看法伪装成普遍真理。
7. 聊天里的对抗句、金句和口号，只在它真正承载新判断时保留；单纯为了冲而冲的句子改写成普通陈述。

## 交付前检查

- 读起来像正常说话，还是像内容工厂或诊断 AI？
- 核心判断单独拿出来，有没有信息量？
- 第一段是否已经说出核心判断？
- 每一段是否只推进一个主要意思？
- 短句结论和长句解释是否有节奏，而不是整篇同一种长度？
- 需要强调的词是否尽量落在句尾？
- 多个并列判断是否用了少量、可独立理解的中文编号标题？
- 单一观点是否避免了不必要的机械分点？
- 是否按 `social-expression-rules.md` 检查六类句式、近似变体和必要对比的例外？
- 有没有用华丽包装、钩子或刺痛替代事实、例子和逻辑？
- 有没有残留对话、检索或 AI 生成痕迹？
- 有没有为了“有力量”而写得过度绝对？
- 去掉标题后，正文是否仍然自然成立？

## 怎么测 v1 / v2

同一份材料分别按 v1 和 v2 各写一稿，对照这三件事：

1. 核心判断有没有更具体，还是只是语气更冲。
2. 对比句和设问是变少了，还是被换成了另一种模板。
3. 读起来还像作者本人，还是开始像 dontbesilent 或小红书文案。

测稿时只交一版 v2，除非用户明确要求两版对照。
