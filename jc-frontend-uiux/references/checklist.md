# 设计自查清单（阶段 3 必读）

逐项给出「删除 / 替换 / 保留」，不允许沉默地「通过」。凡涉及颜色与对比度，用 `scripts/color_audit.py` 拿数值说话。

## A. 冗余检查（多余的字、多余的元素）——与意符分开

- [ ] 每个元素通过两问测试：①它承载信息或操作入口吗？②删掉后新用户 5 秒内还能说出「我在哪 / 这是什么 / 我能干嘛」吗？两问都指向可删 → 删；任何一问指向意符 → 弱化不删除。
- [ ] 保留下来的意符（导航返回、可点击暗示、当前状态、操作反馈）在默认态可发现，不只存在于 hover 里。
- [ ] 渐进披露分层正确：核心功能常驻可见；次要功能弱呈现；高级功能收进详情/菜单且入口可发现。
- [ ] 删的是功能还是线索？整个功能下线 → 连带界面删除，安全；功能还在却只删入口线索 → 事故，回退。
- [ ] 没有开发态 / 演示态文案混入产品界面（版本标签、数据免责声明、编者注释）。
- [ ] 标题、标签、提示没有重复上下文已表达的信息。
- [ ] 占位功能（示例按钮、演示入口）没有伪装成产品功能。
- [ ] 导航元素不需要常驻容器；默认裸文字，反馈（hover 底 / 焦点环）发生在交互时。

## B. 层次检查（多余的分栏、多余的线）

- [ ] 区域底色 ≤2 级（导航 / 工作）；卡片与浮层用材质色 + 阴影，不算区域底。
- [ ] 区域内没有 border 横线；分层全部用间距（24/32）与字重。
- [ ] 同底色的相邻区域之间没有分隔线。
- [ ] 没有卡片套卡片；描边没有被用来补底色差的不足。
- [ ] 灰度 / 眯眼测试：不凑近也能读出区域结构。

## C. 颜色检查（不合理的颜色）

- [ ] 没有新增原始色值；全部颜色来自设计 Token。
- [ ] 小面积强调色属于页面色相族（圆环色相距 <90°）；离族色有明确语义职务且面积小、出现短暂。
- [ ] 交互反馈色（hover / press / focus）走 focus-ring / 品牌色 Token，不借语义色。
- [ ] 反馈对比 ≥1.1（不「肉」）；装饰线避开 1.2–1.4（不「虚」）；文字 ≥4.5:1。
- [ ] 状态不只靠颜色表达（文字 / 图标 / 结构至少其一）。

## 案例库：2026-10-10 一次 AI 编辑工作台界面迭代实录

每个案例都是「原话 → 显影断言 → 修法」。

| 原话 | 显影断言 | 修法 |
| --- | --- | --- |
| 界面乱、东西多 | 面包屑与侧栏重复；上下文行与文档区重复；版本标签与工具面板重复 | 整条位置栏删除；上下文行、头部标签删除 |
| 演示感重 | 开发态文案（「演示数据」「请按真实内容确认」）混入产品界面 | 删除或替换为正式措辞（「请核实事实，采用后才会更新原文」） |
| 这两个按钮删掉，正式版不需要 | 删的是整个功能（连后端逻辑都不要），不是删线索 | 连带删除，安全 |
| 侧栏头重 | 标题 + 入口按钮 + 分隔线三层 | 合并为「‹ 返回」裸文字返回链接，hover 出按钮形——意符保留，只降视觉重量 |
| 分栏多、底色不一致 | 三级底色明度差 1.03:1，底面不分，层次全靠 7 条描边 | 底色收敛两级（导航 stage / 工作 paper）；区域内横线清零；全页仅留 1 条结构线 |
| 卡片边框重 | 底面不分时用描边补层次 | 卡片去描边，启用暖色静置阴影 |
| 突兀的紫色 | AI 紫 H=284°，与色相簇（38–90°）圆环距 114°；C=0.214 > 品牌橙 0.194；6.3:1 成全页最强非文字信号 | 聊天头图标 → 暖灰；紫色只保留给瞬态语义（运行态） |
| 紫色竖线（截图） | 放大后发现是分隔柄 hover 态被染成紫色——交互态问题，静止态不存在 | hover 线 / 焦点环 → focus-ring（品牌橙） |
| 分割线锐利 | 静止态线条对比仅 1.28:1（偏虚），「锐利」感来自那条紫色 hover 线 | 同上，颜色修正后自然解决 |
| 橙色选中块不舒服 | 选中 tint 对侧栏底 1.03:1（无边界）且色度 2.6 倍 → 无形色渍 | 白 + 暖阴影（1.13:1 且低色度） |

## 反面教训（容易回潮的错误）

1. **把意符当噪音删掉**：纯扁平化翻车（NN/g 实测导航耗时 +22%）就是这么来的。精简的判定标准不是「占不占地方」，而是「删掉它，用户的哪个判断会变慢或出错」——答不上来的才能删。
2. **没放大截图就下结论**：差点把 hover 态的紫线当成静态设计问题去改装饰线 Token。先定位，再量化，最后才改。
3. **用语义色当交互色**：AI 紫是「AI 身份」的语义色，拿它当 hover / focus 色会让全页出现离族高饱和点。交互色只有 focus-ring / 品牌色一个来源。
4. **加线解决分不开的问题**：分不开的根因永远是底色差不够或间距不够，加线只是把失败藏起来。
5. **「我看着好多了」当验证**：改完必须重新量化；对比度与 OKLCH 数值回到区间才算关闭问题。
