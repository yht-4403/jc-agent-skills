# jc-html-lecture：可标注的 HTML 讲解页

## 适用与边界

用：内容有结构、要反复回看、要图的知识讲解；用户要在页面上标「不懂」再回来拓展；已有页面增量补章。
不用：一两句话能说清（走对话）；纯代码排查；用户只想听（走 `jc-learning` 路径 A）。

内容由 `jc-learning`（工具清单、节奏）和 `jc-plain-explainer`（贯穿案例）决定。本 skill 只管「装进页面」和「能被继续拓展」。

## 两种交付形态

**linked（默认，生成时用）**：页面用 `<link>`/`<script src>` 指向同级 `./assets/`。多页共用一份运行时，改一处全生效。

**single（交付/分享前用）**：跑一次打包脚本，把 `./assets/` 全部内联成一个自包含 HTML。换目录、发给别人、双击都能用。

```bash
python3 scripts/inline.py 页面.html          # 产出 页面-单文件.html
python3 scripts/check.py 页面.html --single  # 校验是否还有残留外链
```

生成时不要手写内联的 CSS/JS：那是每页约 12K token 的重复劳动，且容易写错。链接 + 脚本打包，token 和可用性两头都拿到。

## 生成顺序（省 token 的关键）

1. 把整个 `assets/` 目录复制到目标文件夹（页面同级）。漏了这一步，页面打开就白屏，`check.py` 会直接报错。
2. 读本文，**不要读 `style-core.css`、`jc-note.js`**。样式直接用下面的类名表，脚本只加几行引用。
3. 复制 `references/page-skeleton.html` 的结构，只复制一次，之后按节往里填。
4. 内容按 `jc-learning` 的方法写；每节至少一张图或一段代码。
5. 收尾跑 `python3 scripts/check.py 页面.html`，把阻塞问题修掉。
6. 要分享再跑 `inline.py`。

## 可用类名（照用，不要自建样式）

| 类名 | 用途 |
|---|---|
| `.hero` `.lede` `.eyebrow` | 首屏：标题、一句话导语、上方小字 |
| `.ch-head` `.ch-num` `.ch-kicker` `.ch-lede` | 每节开头：编号、一句定位、h2、导语 |
| `.fig` `.fig-cap` | 图表容器与图注（图注写「看什么」，不复述图内文字） |
| `.formula` `.eq` `.cap` | 居中的公式块 |
| `.note` `.key` `.warn` `.danger` | 提示框四档：补充 / 关键结论 / 注意 / 危险 |
| `.tbl-wrap` `.tbl` | 表格（外层必须有 `.tbl-wrap`，窄屏才不撑破） |
| `.code` `.code-bar` `.code-slot` | 代码块（内容由 `jc-code.js` 渲染，不写 `<pre>` 手拼） |
| `.quiz` + `<details>` | 节末自检折叠 |
| `.side` `.toc` `.side-foot` | 左侧目录（1000px 以下自动隐藏） |
| `.topbar` `.top` `.foot` | 顶栏、回到顶部、页脚 |

配色只用 `var(--ink)` `var(--ink-2)` `var(--muted)` `var(--teal)` `var(--amber)` `var(--risk)` 及其 `-soft` 版本；字重 400/500（标题 600），不用 700。内联 `style` 尽量不写，超过 40 处就该收进类。

图用内联 SVG，`viewBox` 宽度以 880 为基准，图内文字 10–12px（最小 9.5px）。**能用一个表格或三个方框说清的，不要画复杂坐标**——手写十几个 `<path>` 既费 token 又容易错位。

## 抽象概念怎么讲：靠算例，不靠比方

读者反馈的实证：「看到算这一步才明白，前面的比方和图都有点蒙，问题倒是看得懂。」

顺序固定为 **问题 → 数字算例 → 比较 → 术语 →（可选）画面**：

1. **问题**：要做一个什么决定，只有两个选项。
2. **数字算例**：3–8 个样本，手算 30 秒能完，**必须算出两个候选答案的具体数值**。
3. **比较**：两个数一摆，哪个小、差多少。
4. **术语**：这时才给名字，并说明它对应刚才算的哪一步。
5. **画面**：图或比方只用来记住，必须能还原成数字，还原不了就删。

三条配套规则：

- **算例里放一次失败**：误差直接相加得 0、切完左边最纯但总误差更大、顺着切点试误差不是单调下降。出现荒谬 → 停 → 问哪里不对 → 这时才给工具 → 同一组数字重算。
- **派生量必须写出来源**：读者会问「为什么要让它变大」，就说明它是派生量。增益 = 切前误差 − 切后误差，误差小才是目标；组内散度就是误差本身。给出派生量后紧跟一句「它等于什么原始目标的变化」。
- **别用方差分析的说法**：「解释了多少差异」改成「误差从 1.875 降到 0.833」，后者读者能自己核对。

三种典型失败：词没有画面（平方、贪心、乱）、一句多词（组间/组内/方差分析挤在一句）、断言解释断言（「不是 A，而是 B」）。对应硬规则：一句话最多一个新词；术语首次出现必须绑一组能对比的数字；不用「不是……而是……」解释概念。禁用句式与写作偏好同 `../jc-learning/SKILL.md`。

## 页面结构

顶栏（课题 + 讲次 + 返回 + 进度）→ 首屏（一句话说清解决什么 + 怎么读 + 四个元信息）→ 左侧目录 → 8–10 节正文 → 页脚（术语表 + 来源与边界）。

每节固定：编号 + kicker + h2 + 导语 + 正文 + 至少一个图或代码 + 一个自检折叠。连续两节纯文字就补一张图。首屏不放大段术语。

规模：单页 ≤10 节、正文 ≤35KB。超了拆附录页 `YYYY-MM-DD-{课题}-附录02.html`，主页面只加一条链接和一句摘要，文档地图登记页面清单。不要靠删内容压体积。

## 标注运行时

`</head>` 前和 `</body>` 前各加一行，其余什么都不用写：

```html
<link rel="stylesheet" href="./assets/jc-note.css">
...
<script src="./assets/jc-note.js" data-jc-note
        data-doc-id="{课题缩写}-{讲次}" data-doc-title="{页面标题}"></script>
```

- `doc-id` 定了就不改，它是 localStorage 的 key，改了等于清空用户的标记。
- 只有一种标记「不懂」，不接 AI，页面里不放任何 key。
- 支持跨段划线、就地评论框、抽屉清单（定位/删除/复制清单/下载 .md）。
- 实现细节（跨段拆分、空白宽容匹配、评论框定位）见 `references/note-internals.md`，**改运行时才读**。

## 增量拓展流程

1. 读文档地图，**不读整页 HTML**。
2. 读「看不懂清单」。
3. 清单里的章节名对上文档地图的 `id`，Grep `id="sX"` 只读那一段（前后各 20 行足够）。
4. 只改那一节；优先「加一个小节」而不是重写整节，避免锚点位移。
5. 更新文档地图：版本 +1、变更记录、章节索引、标注清单状态。
6. 跑 `check.py` 复核标签闭合与脚本语法。

## 自检清单

- [ ] `check.py` 通过（标签闭合、assets 存在、doc-id 非空）。
- [ ] 双击能开，控制台无报错；1000px 与 500px 都不横向溢出。
- [ ] 每个 `id` 唯一，目录每项都能跳到位。
- [ ] 文档地图的章节表与页面实际 `id` 一一对应。
- [ ] 标一段跨行文字 → 弹评论框 → 刷新后高亮和备注都在。
- [ ] 演示数字标了「假设」；每个抽象概念前有一个读者能自己算的失败例子。
- [ ] 要分享的话，已经跑过 `inline.py` 并验证单文件可用。

## 反模式

- 每次拓展都重写整页，锚点、标记、目录全乱。
- 把用户的提问和标注原文写进正文（那是旁白）。
- 图里塞小作文，或用图替代机制解释。
- 引用 CDN、外链字体、外部图片，换台机器就白屏。
- 手写内联 CSS/JS（多花 12K token，还容易和内联脚本里的 `</script>` 打架）。
