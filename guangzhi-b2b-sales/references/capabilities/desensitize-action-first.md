## I — 方法论骨架 (Interpretation)

大多数"做不成"不是方法问题，而是**动作没做**。作者给的操作解法很朴素：把所有"可做可不做"的默认值改成"做"——可说可不说的话就说，可加微信就加，可自我介绍就统一自我介绍。做多了，被拒绝的心理成本自然归零，这叫**脱敏**。

三条配套机制：

1. **动作与情绪脱钩**：无论内耗多严重，先把必要动作做完。"动作优先、流程先行"——先不考虑情绪，把动作做到位。
2. **重复三次起步**：一件事做三遍，成功率显著高于只做一遍。电话被拒、加微信没通过、邀约被拒、拜访被挂——都只是第一遍。
3. **起量先行**：技巧是在有量的基础上才成立。量不够时谈技巧是自我安慰（三量法则：开发量、拜访量、应酬量——第三项的原义是饭局应酬量，线上业务须迁移为主动触达量，见 B 段）。

另一条容易忽略的纪律：**别拿客户练表达**。说话磕巴要练，但客户不是练功房——一天拜访的说话量根本不够训练；要到专门场景（录视频、回听、复述）去练。

## A1 — 案例 (Past Application)

### 案例 1: 作者靠回看早期视频改掉发声问题
- **问题**：早期说话用"嗓子眼"，缺乏气场。
- **方法论的使用**：他翻自己两年前的视频、回听反馈，刻意改成丹田发声。
- **结论**：表达是可训练的，且训练必须发生在专门场景，不在客户面前。
- **结果**：语调与气场明显改变。（p164 / p204-205）

### 案例 2: 作者亲历——所有新手动作都伴随紧张
- **问题**：早期打电话紧张、约饭不好意思，怀疑自己不适合做销售。
- **方法论的使用**：他把这段当作样本讲给学生：紧张不是个人缺陷，是必经阶段；处理方法是照做动作，而不是等不紧张了再做。
- **结论**：情绪不需要先解决，动作可以先完成。
- **结果**：新手期的自我否定被替换成"先做够量"。（p62）

### 案例 3: 录视频不做心理准备、不理评论
- **问题**：公开发言容易被评价反噬。
- **方法论的使用**：作者以自己为"低心智成本"样本——表达前零内耗，表达后不反刍评价。
- **结论**：脱敏的终点是"做完了就过去"，不是"做得完美"。
- **结果**：表达频率提高，心智成本下降。（p68）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这张卡？
1. 消息写好了却不敢发，反复修改、拖到错过时机。
2. 被客户拒绝或冷落之后，几天不想再联系任何客户。
3. 一直在准备（看资料、听课、改话术模板），但实际触达量很低。
4. 觉得自己"不适合做销售"，想把副业停掉。
5. 想练表达/话术，但一练就想拿真实客户试。

### 语言信号
- "这条消息我不敢发 / 发了会不会被讨厌"
- "被拒了之后有点不想再联系客户了"
- "我是不是不适合做销售"
- "我最近一直在学东西，但没怎么去谈客户"
- "怎么练话术 / 能不能拿客户练"
- "I'm afraid to send this / I keep procrastinating / maybe I'm not cut out for sales"

### 与相邻能力的区分
- 与 **客户卡点诊断**（★ 最易混）：本卡治的是"**不敢做动作**"，诊断卡治的是"**客户为什么不动**"。如果客户不回是因为比价、权限、报价结构问题，本卡无效——做再多次动作也不会回。判断标准：你能说出客户卡在哪 → 走诊断卡；你只是不敢联系 → 走本卡。
- 与 **跟进节奏与在场感**：本卡的"量"是**策略性起量**（量决定成单概率），跟进卡的"节奏"是**单个客户的接触编排**。量不够走本卡，节奏乱走跟进卡。
- 与 **沟通与潜台词**：本卡解决"不敢说"，沟通卡解决"说得不对"。发出去之前反复改措辞改到不敢发 → 本卡。
- 与 **三问验证**：本卡的加量应发生在验证之后，否则是把量砸在不值得的客户身上。
- 与 **领作业**：领作业要求每次接触有产出；本卡只要求动起来。二者冲突时（不敢要作业就不敢联系），先过本卡再到领作业。

## E — 可执行步骤 (Execution)

1. **设默认值：把"可做可不做"一律改成"做"**
   - 动作：列出你这周所有"可做可不做"的沟通动作（加微信、发一条有价值的信息、做一次自我介绍、多问一句），把它们写成一个清单，默认全部执行。
   - 完成标准：产出一张"本周默认执行清单"（≥5 条），每条都是**一个具体动作**，不是"多联系客户"这种模糊项。
   - 判停条件：若某条动作会让你违反合规或职业边界（如承诺做不到的事）→ 划掉，不属于本卡范围。

2. **按量执行，不按感觉执行**
   - 动作：给本周定三个数字（触达次数 / 有效对话数 / 提出请求数），每天只记录完成数，不评估"今天状态好不好"。被拒后强制在 24 小时内做下一个动作，不允许间隔空窗。
   - 完成标准：产出七个每日计数；周末能回答"三个数字分别完成了多少"。
   - 判停条件：若量达标但连续两周零进展 → 停止加量，转 `three-verifications`（可能客户选错了）或 `client-stuck-diagnosis`（可能方法不对）。

3. **练表达去专门场景，不拿客户练**
   - 动作：为最常说的 3 段内容（自我介绍、产品一句话价值、报价说明）各录一遍音或视频，回听、标记卡点、再录一遍；**不**在客户面前试新版话术。
   - 完成标准：产出 3 段录音/视频的第 2 版，并写下一处具体改进（语速、口头禅、结构）。
   - 判停条件：若回听时发现真正的问题是内容不清（不是紧张）→ 转 `communication-subtext` 改内容结构。

## B — 边界 (Boundary) ★

### 不要在以下情况使用
- **问题出在策略或客户质量上**：客户不回、成交率低，如果根因是客户选错或报价结构，加量只会更累（转 `three-verifications` / `pricing-response`）。
- **需要休息或健康受损时**：脱敏不是强迫自己硬扛；长期焦虑、失眠属于需要处理的信号，不是"动作量不够"。
- **用"多练"替代"想清楚"**：作者自己反对拿客户练表达；本卡也不是"用行动掩盖思考"的许可证。

### 原文中警告的失败模式
- **等内耗过去再行动**：把"等状态好了再做"当策略，结果等到五年十年（反例 `cl-ce-13`）。
- **用学习、理论、客户现场替代真正练习**：把陈述性记忆当程序性记忆，越学越不敢做（反例 `cl-ce-28`）。
- **状态与生命力缺失**：背话术的机器人，同一套词跨渠道都失效（反例 `cl-ce-29`）。
- **姿态失衡**：脱敏不等于卑躬屈膝、自我矮化——那是另一个极端（反例 `cl-ce-05`）。

### 作者的盲点 / 时代局限
- **⚠️ 画像降权（必读）**：CHARTER 把"新人成长/心态"列为提取优先级**第 5 级（降权）**——使用者已过新手期、且以副业方式经营。所以本卡的适用面比原书窄：它只治"**不敢做**"，不治"**做得不对**"。
- **三量法则的口径以原文为准**：原文 p291-294 是「**开发量 / 拜访量 / 应酬量**」（电话开发量 / 客户拜访量 / 饭局应酬量）。OVERVIEW 曾记作"客户量/拜访量/电话量"，属复述偏差（见 `verdicts/DECISIONS.md` D4）。线上代充业务里第三项必须迁移成"主动触达量"，**不是**去攒饭局。
- 原书的量建立在**线下拜访与电话开发**上（一天拜访量、一天打几十通电话）。线上代充的接触以微信为主，量的口径要换算成"主动发起的有价值接触次数"，机械照搬电话量会让动作变形为骚扰。
- 作者立场的盲点：作为培训师，他倾向把结果归因于"个人努力与动作量"，系统性低估产品、价格、供应链的决定性作用。本卡尤其要防止这种归因被用来自责。

### 容易混淆的邻近方法论
- `client-stuck-diagnosis`：不敢做（本卡）vs 客户不动（诊断卡）。
- `followup-rhythm`：策略性起量（本卡）vs 单客户节奏编排（跟进卡）。
- `communication-subtext`：心理成本（本卡）vs 表达质量（沟通卡）。

### 来源之间的边界差异
- 无源间分歧。但"动作先行"这一主张在书中的表述密度极高（p62-63、p72、p114、p135、p169、p297 至少五篇）——**表述密度高不等于证据等级高**：它是同一作者在同一时期的反复强调，仍属单源多域（B 级），不能读成"多方验证过的结论"。
