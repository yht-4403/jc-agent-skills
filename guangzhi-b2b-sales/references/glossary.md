## 四、术语与能力卡的对应

- `client-stuck-diagnosis` ← 六因表、三状态、客户状态（义项 A）
- `communication-subtext` ← 潜台词（单一来源）、零信息量、升通道、选择权
- `followup-rhythm` ← 事做三遍、熟悉度原则、闭环汇报、三量法则、掌控感
- `relationship-settlement` ← 现场结账、小恩小惠、晴天修屋子、转介绍、经营参与感
- `pricing-response` ← 询价客、两段低价法、算账、无预算即非客户
- `push-timing` ← 筹码、求上得中、以进为退、难事必须逼
- `three-verifications` ← 职权 / 性格经验 / 项目状态三问、识人看能动性
- `next-step-assignment` ← 领作业（义项 A）、四件套、倒推法
- `desensitize-action-first` ← 脱敏、事做三遍、起量、可说可不说一律说

## 五、合规红线术语（只作边界，不给操作）

**点位 / 控制点 / 塞控制点 / 过磅 / 贯口**：这些术语在原书中带有明确的操作与灰色空间。本包**只保留其分析与风险含义**（如"资源只投控制点"的判断口径），**不提供任何操作步骤**，相关内容只出现在各卡的 B 段边界与 `rejected/` 明细里（见 `verdicts/DECISIONS.md` 与 OVERVIEW 批判段第 4 条）。
