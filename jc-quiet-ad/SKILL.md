# JC Quiet Ad

## 这套东西解决的是什么问题

户外大屏是「三秒决生死」的媒体。但三秒里的瓶颈不在"看见"，在"愿不愿意看"。

人走过一块屏，第一件事不是读，是归类：这是广告吗。判为是，闸门落下，后面的冲击力全部作废。过去三十年那套做法——满幅产品图、明星脸、加粗描边、动效轮播、限时倒数——在提高冲击力的同时也在**降低识别成本**：它让人更快、更确定地认出这是广告，于是更快地屏蔽。

所以这个行业最大的一笔成本已经不是媒体费，是观众的免疫力。

这套方案换了个优化目标：不优化吸引力，优化**识别延迟**。让大脑晚一步归类，把三秒里的阅读时间抢出来。

一句话：**别的广告在争"被看见"，它在争"没被认出"。**

## 先判适用性

这套方案脆弱，用错地方就是白烧预算。三条同时成立才可用：

| 条件 | 判据 |
|---|---|
| 品牌已有认知 | logo 缩到看不清，仍有人知道是谁 |
| 品类是发现型 | 观众不需要被解释"这是什么"，只需要被提醒"我想要" |
| 节点自带话题 | 全民购物节、城市事件这类高噪声场，安静本身才成为反差 |

缺一条，回到常规做法。完整边界见文末。

## 五个手法

### 一 · 借低价值界面的形

把画面做成 PPT、文档、备忘录、聊天记录、评论区。

为什么有效：PPT 是工具的产物，不是作品。工具产物自带"非商业动机"的暗示——有人加班做出来给同事看，不是花钱做出来给你看。观众的第一判断从"这是广告"变成"这放这么大个 PPT？"，闸门就晚了半秒。

做法：浅底、无装饰、无边框、常规字重、边距像文档一样宽。整块文字像一页还没排完的稿。

### 二 · 品牌名下沉，logo 收缩

logo 缩到"存在但不宣告"的程度。真正放大品牌的是正文里的几个字——"在小红书买的"——它和正文同字号、同字重，混在句子里当事实用。

这是整套里最反直觉的地方：**品牌名的字号没变大，变大的是它的语境**。从"品牌在说自己"变成"用户在说品牌"。

做法：正文自然出现一次品牌名，之后不再重复；底部只留一个胶囊 logo 当落款。

### 三 · 把广告语写成人话

不写"欢迎来小红书购物"，写"本来今天不跑步的，但是在小红书买的新鞋到了"。

判据只有一句：**念出来，像不像一个人在跟另一个人说话。** 不像就重写。

公式：一个具体场景 + 一句不该说出口的小心思 + 品牌名作为事实出现。展开见 `references/copy-formula.md`。

### 四 · 图片主动降质

用普通人笔记里的手机随拍：有点糊、有生活痕迹、抠图边缘不干净。

这条最难通过甲方。传统广告逻辑里这叫"降低品质感""不专业"。但做真实感类广告时，**任何提升品质的动作都在削弱真实感**——精修图和"随手拍"摆在同一画面里互相打脸，观众信的是后者。

做法：嵌在文字行里当"一个词"用，不加投影、描边、圆角卡片。高度约 1.3–1.5 倍字高。嵌在句中而不是句末、也不是旁边，因为那是表情包和聊天记录的排法——图与字在同一条线上流动，语境立刻变成私人对话。

### 五 · 让媒介自指

最少人用的一招：让屏、框、环境本身成为创意的一部分。

案例里那版取景框——大屏被做成一个空画框，框里是真实的江景和天际线，只有底边一条窄白带写着"今天这一身，连江景都只能当背景"。媒介消失了，只剩内容。

做法：先问这个位置本身有什么可借的——朝向、地标、天气、人流、对面那栋楼。想不出来再写文案。

## 视觉规格

完整参数、换算表和栅格在 `references/visual-spec.md`。主干：

| 项 | 值 | 为什么 |
|---|---|---|
| 底色 | `#EDE3FA` 丁香紫 | 界面色，不是广告色。白底黑字＝海报语法，一眼归为广告；纯黑＝发布会，太郑重 |
| 文字 | `#1F1D24` 近黑带紫调 | 纯黑对比过硬像标题；带紫调让字与底同源，整块软下来 |
| 辅助灰 | `#6B6570` | 活动说明、落款小字 |
| 品牌红 | `#FF2442` | 只用于 logo 胶囊和一个极小的圆标，合计面积 ＜1% |
| 字体 | 思源黑体／苹方 SC | 无衬线，不用衬线体和手写体 |
| 字重 | **400，只用 400** | Bold 是"喊"，Regular 是"说" |
| 正文字高 | 屏高 4.5%–5% | 笔画细，靠字号补，不靠字重补；最终按观看距离核算，见 spec |
| 每行字数 | 6–8 字 | 一行一口气读完，不换气 |
| 行距 | 1.9–2.0 倍字高 | 松，像没排完 |
| 文字块宽 | 屏宽 51%–68% | 两侧留白大于文字块自身高度 |
| 品牌区 | 屏高 15%–18%，贴底三层递减 | 它是落款，不是主标题 |

`assets/template-screen.html` 是可改文案直接出稿的参数化样张，竖屏横屏各一版，带辅助线开关。

## 免疫触发器

出现任意一项，这套方案就废了。逐条删。

- **视觉**：明星脸／金色渐变大字／爆炸贴／倒计时数字／满减券图形／动效／裸眼3D／产品精修图／粗描边立体字／多图拼贴／大块二维码
- **文案**：限时／最后一天／仅剩／全场／包邮／低至／狂欢／盛典／震撼／首发／尽享／开启
- **标点**：感叹号、连续问号
- **结构**：品牌 Slogan 大字居中 ＋ 产品图 ＋ 促销信息，三段式

## 工作流

1. **过适用性三问**。不过就停。
2. **定场景**。这个产品出现在用户生活的哪个片段里——不是"使用场景"，是"会想起它的那一秒"。
3. **写 8–12 句，只留 1 句**。判据：念出来像人话。
4. **挑图**。从真实 UGC 里找，模糊优先，精修图直接淘汰。
5. **出稿**。按 spec 排 3 版，只微调字号与留白，不改结构。
6. **免疫体检**。拿上面的清单逐条删。
7. **缩略图测试**。缩到手机屏幕大小，隔一米看三秒。

### 缩略图测试

问两个问题：

- 你觉得这是什么？
- 你想读完吗？

答"广告"→ 失败。答"这什么？""一个 PPT？"→ 成立。答"看不懂"→ 同样失败：识别延迟不能变成识别失败。这套方案要的是**半秒的疑惑**，不是三秒的困惑。

## 什么时候不能用

1. **品牌没有认知度。** logo 缩小等于没投，观众读完句子不知道是谁说的，预算全转成公益广告。
2. **需要解释。** 新功能、新品类、新概念，观众连"这是什么"都还没建立，含蓄会变成看不懂。
3. **纯价格战节点。** 目标是今天把人拉进店，需要明确的价格信号。安静在大促里有时是反差，有时是自杀，看你的目标是不是"进店"。
4. **弱注意力场。** 信息流、开屏、电梯海报本来就没有这堵免疫高墙，观众是在"划过"而不是"驻足"，玩含蓄只会被划得更快。
5. **团队接不住"不完美"。** 这套必须有人扛住"图太糊了换一张"的压力。扛不住，做出来的是个四不像。

## 最后一条

这套方案的有效性，建立在**每个细节都不被优化**上。

它最常见的死法不是创意不行，是执行中途有人"帮它变得更好看"：换一张更清楚的图、把字加粗一点、给图加个投影、把底色调白一点。每改一处，就往回退一格。

改稿前先问一句：这个修改是在提升品质，还是在提升真实感？在这套方案里，这两件事是对立的。
