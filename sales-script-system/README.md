# sales-script-system · 真正有用的销售话术体系（Agent Skill）

一个可给 AI Agent（Claude Code / WorkBuddy 等）使用的销售话术 Skill，源自同名书稿《真正有用的销售话术体系——从面客、推荐到成交推进的实战手册》的完整蒸馏版。

核心理念：**好话术不是金句，而是成交结构。** 销售失败多数不是话说得不漂亮，而是顺序错了——客户没信任就推产品、需求没搞清就讲功能、价值没算明就报价、顾虑没处理就逼单。

## 这个 Skill 能做什么

| 任务 | 说明 |
|---|---|
| 生成话术 | 按产品/客户/场景/环节，输出带【变量字段】的可改写话术模板 |
| 异议处理 | 强制走「接住情绪 → 澄清真实顾虑 → 回应核心问题 → 推动下一步」四步法 |
| 销售陪练 | AI 扮演价格敏感型 / 犹豫型 / 强势比较型 / 沉默型 / 懂行型客户进行角色扮演并点评 |
| 复盘分析 | 贴入录音文字或聊天记录，按复盘表逐项诊断，指出最该优化的一句话 |
| 场景速查 | 给出具体卡点（"客户说没钱""怕员工不用"），按 100 场景检索表秒出对应话术 |

覆盖五大场景：**门店导购、直播带货、私域销售、AI 产品销售、B2B 大客户销售**，以及**陌拜获客、建联信任**等全流程九阶段。

## 内置方法论

- **七大环节公式**：开场 → 需求 → 推荐 → 价值 → 异议 → 成交 → 跟进，每个环节一个速查公式
- **经典方法论速查**：SPIN Selling、Challenger Sale、Sandler、MEDDPICC、Value Selling、Solution Selling、FABE、AIDA、PAS
- **需求挖掘四步问题库**：问场景 → 找问题 → 放大影响 → 引出期待结果
- **成交推进五式**：试探 / 选择式 / 总结式 / 稀缺式（必须真实）/ 风险逆转
- **完整实战案例**：洗烘套装、奶瓶消毒柜、按摩椅、AI 笔记、CRM 采购、8 万培训营价格解释等


## 安装使用

### Claude Code

```bash
git clone https://github.com/<YOUR_USERNAME>/sales-script-system.git ~/.claude/skills/sales-script-system
```

之后在对话中直接说：「帮我把这个产品写成直播话术」「陪我练一下客户嫌贵的场景」「复盘这段聊天记录」。

### WorkBuddy

将仓库内容复制到 `~/.workbuddy/skills/sales-script-system/` 即可。

## 设计原则

- **渐进式披露**：SKILL.md 只放高频骨架（约 9KB），完整话术案例按需从 references 加载，不浪费上下文
- **变量字段**：所有话术保留【客户场景】【关键需求】【证据】等占位符，可按自己产品动态改写，而不是死背固定句子
- **合规红线**：稀缺必须真实、不虚构数据、不夸大承诺、讲取舍比只讲优点更可信
- **环节完整性**：没做需求挖掘就想要逼单话术时，Agent 会先提示补环节再给话术

## 适用对象

门店导购、直播带货、私域销售、电话销售、企业服务销售、AI 产品销售、招商与大客户销售，以及任何想把话术方法论交给 AI 助手持续使用的个人和销售团队。
