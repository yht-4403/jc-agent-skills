# 一键安装提示词：去 AI 味核心

这套是底座，其他套装都假设它已装好。把下面整段复制发给你的 AI：

```text
把 https://github.com/yht-4403/jc-agent-skills 仓库里的 jc-no-ai-flavor-latest 这个技能装到我当前的平台：克隆仓库，把这个目录复制（或软链）到我当前平台的 skills 目录——WorkBuddy 用 ~/.workbuddy/skills/，Claude Code 用 ~/.claude/skills/，Codex 用 ~/.codex/skills/。装完告诉我它管什么，然后从下一条回复起按它的规则输出：第一句给结论、先守住重要信息、正文简短、结尾告诉我下一步怎么追问。
```

装好后验证：随便问一个复杂问题，看它是不是先给结论、段落变短、结尾告诉你下一步问什么。
