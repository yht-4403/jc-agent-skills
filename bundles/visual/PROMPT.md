# 一键安装提示词：图先行

先装「去 AI 味核心」（bundles/core/），再把下面整段复制发给你的 AI：

```text
把 https://github.com/yht-4403/jc-agent-skills 仓库里的 wb-visualizer-guide 和 jc-markdown-visual-writer-latest 两个技能装到我当前的平台：克隆仓库，把这两个目录复制（或软链）到我当前平台的 skills 目录——WorkBuddy 用 ~/.workbuddy/skills/，Claude Code 用 ~/.claude/skills/，Codex 用 ~/.codex/skills/。如果我不是 WorkBuddy，只装 jc-markdown-visual-writer-latest 就够。装完告诉我它们各管什么，然后从现在起，有两步以上流程、结构或对比的内容，先给我一张图再配文字。
```

装好后验证：让 AI 解释一个多步骤的流程（比如「下单到收货发生了什么」），看它是不是先画图。
